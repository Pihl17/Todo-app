# Todo-app
## Introduction 

ToDo App is a task management application developed in C# as part of a group project. The application allows users to create, manage and track tasks through both a Windows Forms application and a Web application that shares the same business logic. 

Users can create tasks with titles, descriptions, priorities, deadlines, repeat intervals, checklists, and tags. Tasks can be updated throughout their lifecycle and viewed in a calendar to provide a better overview of upcoming deadlines and recurring tasks. 

 

## Features 

The application supports the following functionality: 

- Create, edit and delete ToDos 

- Add titles, descriptions, priorities and deadlines 

- Add and manage checklists 

- Add and manage tags 

- Mark tasks as NotDone, InProgress or Done 

- Create recurring tasks with daily, weekly, weekday, monthly or yearly repetition 

- Automatically handle recurring tasks when they are completed 

- View deadlines and recurring tasks in a calendar 

- Sort tasks by dealine and priority 

- Change the save location for application data 

- Use both a Windows Form application and a Web application with a shared business layer 

 

## Getting started  

This project requires: 

- Visual Studio 

- .NET 10 SDK 

- .NET Desktop Development workload 

- ASP.NET and Web Development workload 

- Windows for running the Windows Forms Application and UI tests
